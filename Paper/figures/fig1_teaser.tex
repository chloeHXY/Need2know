\caption{\textbf{Why $\mathcal{E}/\mathcal{N}$-aware rewriting is needed.}
A user query routinely entangles \textcolor{\colE}{task-essential spans
$\mathcal{E}$} (answer-bearing clinical signals) with
\textcolor{\colN}{task-non-essential sensitive spans $\mathcal{N}$}
(location, family). Forwarding the raw query maximises utility but
leaks $\mathcal{N}$; PII redactors mask only canonical PII categories,
so non-PII sensitive context still leaks while answer-decisive
evidence is partly destroyed. Our rewriter is trained to remove
$\mathcal{N}$ while preserving $\mathcal{E}$, occupying the
high-utility/low-leak region of the privacy--utility plane.}
