$^{\star}$\,\textit{Direct LLM} sends the unprotected query to a remote API and

rewriter, exposing no information off-device; therefore, its privacy columns are
collapsed as \textit{on-device} instead of repeated not-applicable dashes. It
also defines the utility reference (\,$\Delta$=0\,) for the ``$\Delta$ vs.\ Local''
column, computed as the mean of the General and Medical utility gaps relative to
\textit{Local Only} of the same aggregator. SLR/NE: lower is better;
